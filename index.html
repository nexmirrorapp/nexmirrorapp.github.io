Kya kya milta hai

Laptop Fit

Phone ki screen laptop ki resolution par set, poori screen bhar jati hai. STOP par phone wapas normal.

QR pairing

Ek dafa QR scan, phir har dafa khud connect. Port badal jaye tab bhi phone dhoond leta hai.

Control bar

Screen ke upar: Back, Home, Apps, Close, aur connected phones ki list se switch.

Auto reconnect

Wi-Fi toote to khud dobara jurta hai aur screen share wapas chala deta hai.

Mouse + keyboard

Laptop ke mouse se phone chalayein, keyboard se type karein. Audio bhi laptop par.

Khud update

Engine (scrcpy) pehli dafa khud download aur har dafa update check. Kuch install nahi karna.

Sawal jawab

Windows "unknown publisher" / SmartScreen kehta hai?

App signed nahi hai. More info › Run anyway dabayein.

Password ya banking app par screen kaali kyun?

Ye Android ki security hai, koi app isay band nahi kar sakti. Laptop keyboard se type phir bhi ho jata hai.

Phone nahi mil raha?

Dono ek Wi-Fi par hon, Windows Firewall popup par Allow, router mein Guest network / AP isolation band ho. Phone restart ke baad Wireless debugging dobara ON karein.

Phone ki screen ajeeb size par atak gayi?

NexMirror mein Reset Phone dabayein.

Konsa Android chahiye?

Wi-Fi pairing ke liye Android 11 ya naya. USB cable se Android 5+ bhi chalta hai.

Internet par door se?

Abhi ek hi Wi-Fi par. PC ↔ Android, PC ↔ PC aur door se (P2P) wala version tayyar ho raha hai.
